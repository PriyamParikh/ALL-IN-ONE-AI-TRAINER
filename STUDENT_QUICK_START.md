# All in One AI — Student Quick Start

## Choose your studio

- **Blue Image AI:** “What is this whole picture?”
- **Green Object AI:** “Where are the objects in this picture?”
- **Purple Pose AI:** “Which body pose is this?”
- **Orange Audio AI:** “Which sound did the microphone hear?”
- **Teal Data AI:** “What can a spreadsheet predict?”

## Safe first activities

1. Image AI: Bottle vs Mobile vs Scale.
2. Object AI: Bottle and Mobile in the same camera frame.
3. Pose AI: Hands Up vs Hands on Waist.
4. Audio AI: Clap vs Whistle vs Background.
5. Data AI: Choose a clean classroom CSV and predict one label column.

Always use balanced examples and test the model on new examples it did not train on.
